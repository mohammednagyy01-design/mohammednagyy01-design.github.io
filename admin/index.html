من هنا تعدّل النصوص والمشاريع والصور والباسورد، وتنشر بضغطة واحدة.

إزاي أجيب الـ token؟ (مرة واحدة)
  1. افتح github.com/settings/personal-access-tokens/new
  2. الاسم: portfolio-admin، والمدة اللي تناسبك.
  3. Repository access: اختار Only select repositories وحدد الـ repo بتاع الموقع بس.
  4. Permissions > Repository permissions > Contents: Read and write.
  5. اضغط Generate token وانسخه هنا. التوكن بيتحفظ في المتصفح بتاعك بس.
